## Global instructions

Before creating each page:

- Inspect the existing website to understand the logo, color palette, typography, layout, and conference identity.
- Inspect `img_new/`.
- Use the image filenames as topic cues.
- Reuse the conference logo and color theme.
- Use only real images from `img_new/`.
- Add meaningful text over the images.
- Make each page visually distinct.
- Use creative image blending, overlays, masks, gradients, clipping, parallax, glass effects, layered compositions, or animated reveals.
- Use JavaScript only when it improves the experience.
- Keep performance reasonable.
- Make each page responsive.
- Do not create generic placeholder content.
- Do not reuse the same layout, hero structure, or animation pattern across pages.

## Per page quality checklist

Apply this checklist to every page before marking it complete:

- [ ] Uses 3 to 5 images from `img_new/`
- [ ] Has one clear artistic direction
- [ ] Reuses the conference logo
- [ ] Reuses the existing color theme
- [ ] Adds readable text over images
- [ ] Has a unique layout
- [ ] Has at least one polished interaction or animation
- [ ] Works on desktop
- [ ] Works on mobile
- [ ] Does not link from or alter the main site navigation

## Recommended workflow

Create one page at a time.

For each page:

1. Plan the concept.
2. Select up to 6 images with different concepts
3. Define the composition.
4. Define the interaction model.
5. Implement the page.
6. Test responsiveness.
7. Refine visual polish.
8. Mark the page complete.

## Design rule

Each homepage must feel like it was designed by a different creative studio while remaining consistent with the conference identity.
